# X1 foundation failure matrix

Tracks [X1 #42](https://github.com/ristik/bft-core/issues/42) and its 2026-09-25 transferred list (parent clauses #11.4/.6/.8, #12.6, #13.3/.4/.7, #14.8, #10.7/.9). It connects each root, execution, certificate and transition failure to the test, model or run that establishes its behaviour, with the status of that evidence. It is a status record, not a gate decision. Independent review of this document is row X-43. The review is recorded on PR #351 and corrected rows in place; the rows it added are in section 11.

**Revisions.** bft-core `integration/enshrined-evm` at `7053dfe88bf2f41a98fe16c6a2dc7312ee7cc328` (the #349 merge); ureth `unicity/main` at `b4e7cb0ace07eee70e753241e0139c4d42b516d4`. `file:line` references are resolved at those revisions by script, not typed; a test body that calls `t.Skip` is never cited. M1 historical runs keep their own pins (the `m1-gate-evidence` release assets) and are not restated against this head.

**Status.** MET: the stated behaviour is established by the cited evidence at the cited revision. MET-WITH-LIMIT: established, with the named limit. MISSING: no sufficient evidence; sized S (under a day), M (days), L (a week or more). Evidence kinds: *unit* (in-process test), *fixture* (real-execution fixture in ureth), *process* (child process, SIGKILL), *lane* (paired real ureth devnet), *model* (executable design model).

**Reproduce.** Go tests: `go test ./<pkg> -run '^<Name>$' -count=1` at the bft-core revision. Ureth tests: `cargo test -p reth-unicity-execution <fn>` for paths under `crates/unicity/execution`, `cargo test -p reth-unicity-payload <fn>` for `crates/unicity/payload`, at the ureth revision. The cited tests take no seed or random-input argument; their fixtures are fixed. Lane evidence directories live under `/Users/risto/uni/agre/briefs/devnet-runs/` and in the M1 release assets of `m1-gate-evidence`, **not in this repository** (see `docs/pos/m2-closure-status.md`); each run's pins and command are in its `run-provenance.md`, `run-pins.txt`, `commands.txt` or `lane.log` header. Lanes need the devnet lock `briefs/devnet-lock.sh`. The full suite is `go test ./... -count=1 -timeout 30m` (this repository has no CI).
