The certification gate is in `shardnode/round.go`: after self-verification, any status other than
`StatusValid`, `StatusSyncing` or `StatusAccepted` returns before `Submit`. The new round test pins
the `StatusInvalid` branch directly.

## Disposition of the fifteen `U5d`-skipped v1 adapter tests (X1 row X-45)

Fifteen tests in `engineapi` were skipped with "U5d: v1 adapter fixture awaits migration to the RPC parent witness". The adapter's build and verify paths are v2 only (`deriveV2`; the v1 `Config.Cursor` is retained only for callers of the former API and v2 reads the cursor from the verified parent snapshot, `engineapi/adapter.go`). Each skipped test is now removed, either because a live v2 test covers its property (named below) or because it was migrated to a new v2 test. Negative tests use `errors.Is` where the code returns a sentinel and one isolated change per case; a payload-field divergence returns `StatusInvalid` with no error by design, so those cases assert the status and that the execution client was not called. Each new check was disabled in turn and the named test failed (see the PR description).
